# Poridhi Labs

Hands-on labs for learning about Gemini CLI, Code Assist, and AI coding-agent security.

## Learning path

| Lab | Topic | Level | Estimated time |
| --- | --- | --- | --- |
| [Lab 01: Introduction to Gemini CLI & Code Assist](labs/01-gemini-cli-introduction/) | AI coding agents, security concepts, and identifying common risks | Beginner | 120 minutes |
| [Lab 02: Run Your First Security Audit](labs/02-security-audit/) | Run an audit, interpret its findings, and save the report | Beginner | 120 minutes |
| [Lab 05: Repository Security & Prompt Injection Defense](labs/05-repository-security/) | Inspect repository risks, apply fixes, and verify them with an audit | Beginner | 120 minutes |

Start with Lab 01 and follow the course sequence. Lab 02 builds on the GitHub repository and security concepts introduced there; Lab 05 assumes Labs 01–04 are complete.

## Repository layout

Each lab has its own `README.md` and an `images/` folder for its screenshots and diagrams.
